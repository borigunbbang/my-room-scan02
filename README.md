# 고른 공간

## 주소
https://borigunbbang.github.io/my-room-scan02/

## 어디를 골랐나
- 빌딩 사이 보행 광장. 곡면 유리 건물과 고층 오피스타워, 가로수와 상점가가 둘러싼 열린 공간
- 사유지가 아닌 공공 보행로이고, 문패나 차량 번호판처럼 특정 개인·주거를 가리키는 정보는 화면에 없어 공개해도 되는 곳으로 판단. 다만 촬영 시간대에 행인이 여럿 지나가 얼굴이 작게 담긴 지점이 있음 (아래 "안 나온 자리" 참고)

## 어떻게 찍었나
- 길이 30.8초, 1080×1920(세로), 뽑은 장수 24장
- 카메라가 퍼진 정도 0.1115 (0.1이 기준선 — 통과)
- 나온 점 251만 6천 개 (복원 직후 259만 개에서 0.5~99.5 백분위 밖 튄 점을 버려 정리)

## 폰에서 첫 화면까지
- 아직 실제 기기로 측정 못함 — 페이지가 올라간 뒤 직접 열어서 재는 것을 권장

## 안 나온 자리
- 카메라 경로에서 먼 하늘·원경 건물 쪽은 점이 성글게 잡혀 알갱이가 크게 뭉개지거나 구멍처럼 비어 보임. 시차가 충분히 쌓인 가까운 표면(보행로, 곡면 건물 하부)과 달리 멀리 있는 면은 각도 변화가 적어 깊이 추정이 부정확해짐
- 영상이 세로로 찍혀 화면 위아래(하늘·바닥)가 정보 없이 낭비된 부분이 있음
- 촬영 시간대에 행인이 여럿 지나가 일부 프레임에 사람 형체가 흐릿하게 섞여 들어감. 재구성 자체가 여러 시점을 평균내는 과정이라 사람 형태가 흐트러진 채로 배경에 섞이는 경우가 많았음
